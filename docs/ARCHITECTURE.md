# Архитектура

```
open.spotify.com (страница Spotify, мы её не трогаем)
 └─ content script ── Shadow DOM: кнопка «Моя волна» + оверлей (Preact)
      │   app.js ── фазы: вход → загрузка → онбординг → готово
      │   engine ── подбор и обучение          playback ── очередь и обратная связь
      │   Connect-бэкенд ── опрос GET /me/player, команды play/pause/seek/next/queue
      ▼  chrome.runtime.sendMessage (токены сюда не попадают)
 service worker ── вход PKCE (chrome.identity), токены в chrome.storage.local, прокси запросов к api.spotify.com
      ▼
 Spotify Web API  ◄──►  Spotify Web Player (тот же аккаунт, играет звук)
```

Интерфейс (`src/extension/ui`) ничего не знает про Spotify и движок: он читает `app.state`/`app.view()` и вызывает `app.actions.*`.
Движок (`src/core/engine`) ничего не знает про интерфейс и браузер: ему нужны `api`, `store` и часы, поэтому он целиком
тестируется в Node против мока.

## Алгоритм подбора

Устроен по тому, что известно о Моей волне Яндекс Музыки (статьи Яндекса и публичные доклады): селекторы кандидатов → фильтры → ранжирование
обучаемой формулой → диверсификация. Это **наша реализация** по описанию, а не копия внутренней системы Яндекса.

| Этап | Яндекс (по публичным описаниям) | Songwave |
|---|---|---|
| Кандидаты | Несколько источников: знакомое, похожее на последние, жанры, новое | `familiar`, `expand` (альбомы любимых артистов), `recent`, `genre`, `discovery`, `wildcard`, `similar` (опционально Last.fm) |
| Фильтры | Артист не повторяется 25 треков; в «Незнакомом» нет слышанного | Окно артиста 25 (при нехватке кандидатов сужается ступенями), кулдаун треков, фильтры режимов |
| Формула | CatBoost, ~2000 признаков, обучение на парах соседних событий | Линейная RankNet-модель, 19 признаков, SGD по парам «лайк > дослушал > пропуск > дизлайк», L2 к приору. Своя формула на режим |
| Обратная связь | Пересборка после каждого события | Пересборка резерва после лайка, дизлайка, «больше/меньше такого» |
| Контекст | Время суток, день недели, устройство | Будни/выходные × время суток. Устройство не используем |
| Режимы | Моя волна, Незнакомое, Любимое, Без слов, настроение | Те же. «Без слов» — только эвристика по жанрам и названию |
| Холодный старт | Онбординг | Выбор жанров и артистов, если истории мало |

Чего у нас **нет и не будет без данных Spotify**: popularity, audio features (энергичность, танцевальность, инструментальность),
рекомендаций Spotify, похожих артистов. Поэтому «Спокойнее/Энергичнее» и «Без слов» — приближения по жанрам. В интерфейсе это сказано.
Не реализованы «Популярное» и «Язык» (нужны данные, которых нет в Web API).

Метрики симуляции (`npm test`, `quality.test.js`) печатают долю любимого и нелюбимого, интервал между повторами артиста и сравнение
обучаемой формулы с замороженной. На небольшом каталоге мока обучаемая формула **не даёт заметного выигрыша** над замороженной:
основной вклад вносят жанровые и артистические оценки профиля. Реальную пользу формулы можно оценить только на живых данных.

## Воспроизведение

План: `current` (играет) → `queued` (уже в очереди Spotify, перестроить нельзя) → `reserved` (наш план, пересобирается).
Первый трек запускается `PUT /me/player/play` с контекстом из одного трека, следующие добавляются `POST /me/player/queue`
(горизонт 2). Пока в очереди Spotify есть хотя бы один наш трек, автоплей не включается. Если Spotify всё же ушёл в автоплей
или потерял очередь (доигранный трек сменился на чужой), волна перезапускается нашими треками. Если пользователь сам выбрал чужой трек,
он подхватывается как «Включено не из волны».

Оценка прослушивания: дослушан ≥95% или осталось < 4 с → `complete`; иначе → `skip`. Если Spotify сам перепрыгнул трек из очереди
(недоступен в регионе), он помечается недоступным на 30 дней без штрафа вкусу.

Состояние плеера приходит опросом `GET /me/player` (2,5 с в активной вкладке, чаще у конца трека, реже в фоновой), потому что
у Web API нет push-канала. Волна живёт в одной вкладке (`navigator.locks`).

## Данные

- Токены: `chrome.storage.local`, ключ `mw.auth`, доступны только service worker.
- Профиль вкуса, кэш библиотеки, метаданные: `chrome.storage.local`, ключи `mywave.*`. Экспорт и импорт — в настройках.
- Ничего не отправляется никому, кроме Spotify.
